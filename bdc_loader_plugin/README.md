# BDC Loader

QGIS plugin for the Brazil Data Cube (BDC) of INPE: it searches the BDC STAC catalog, loads image collections
and data cubes as layers read from the Cloud Optimized GeoTIFFs, downloads scenes and crops, and extracts time
series of points.

Open it from the **Raster → BDC Loader** menu or the toolbar button. The **Tour** button in its header walks
through a complete example.

Installation, requirements and development notes are in the README of the source repository:
https://github.com/BaggioCastro/bdc-loader
